# Security policy

Please do not open a public Issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/lanchuske/control-shift-f12/security/advisories/new).

Include the affected version, platform, impact, and minimal reproduction. Never
send private keys, credentials, clipboard contents, or unrelated machine data.
We will acknowledge a valid report, coordinate a fix, and publish only after a
reviewed correction is available.

The project does not request administrator elevation, create services or
drivers, change firewall or enterprise policy, or use SSH. A report that
depends on bypassing those boundaries is outside the supported threat model,
but evidence that Control Shift F12 accidentally crosses one is
security-critical.
